# churn-rate-analysis
Engineered an end-to-end churn analytics pipeline for an OTT subscription dataset (20+ KPIs), identifying a 28.6% overall churn rate and surfacing that monthly-contract subscribers churned at 55.6%, which is 6.7 times the 8.3% annual-contract rate- directly attributing $73.94/mo in MRR leakage and $2,047 in CLTV erosion to six at-risk customers,
